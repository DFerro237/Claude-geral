# Using the archive

This folder keeps backups and historical materials: outputs that have gone out of circulation entirely, replaced contexts, superseded base files and any material that must not be lost. The superseded version of a material still in use does not come here: it stays in the `old/` subfolder of that material's folder, in `06.Outputs`.

The folder can hold only this `README.md` when there is no archived material.

## Authority

Nothing here is a current factual source. A file in this folder records what was valid on the date it was archived. For current facts, figures and decisions, use `04.Materials_and_Sources` and the task's current materials.

Do not use a file from here as a working base without explicit confirmation from the user. When a historical material is needed again, copy it to the applicable folder and preserve the original here.

## How to consult

Consult this folder only when the request involves history, comparison with a previous version or recovery of something that was replaced. Do not read it by default.

## Preservation

Do not edit files in this folder. Do not use it for drafts or for intermediate versions of the current work.
