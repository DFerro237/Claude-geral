# Using the working base files

This folder gathers the base files that should serve as the structural, editorial or technical starting point for preparing or updating the project's deliverables.

Include here, when applicable:

- the latest version of an agenda, report, presentation, spreadsheet, document or dashboard to be updated;
- model files that should be used as the direct base for a new version;
- files whose structure, formulas, layout, history or approved content must be preserved in the new deliverable.

The files in this folder must not be changed directly, unless explicitly authorized.

Use them as a working base and preserve the original version. The updated, revised or derived version must be created in `06.Outputs`.

Before using a base file, confirm that it is compatible with the period, scope, version and objective of the current task.

Do not treat a base file as a current factual source when the data, figures, dates or content depend on more recent materials in `04.Materials_and_Sources` or on other applicable sources.
