# Using the style references

This folder gathers examples of finished materials and other references of form. It serves to recognize
how in-house work is actually written and structured.

The main content is your own finished materials. Institutional templates live in `02.Official_Templates`,
which is a different folder with a different authority.

The folder can hold only this `README.md` when there is no applicable reference.

## What goes in

- your own finished presentations, documents and spreadsheets, inside or outside the official template;
- approved versions of recurring materials (agenda, report, resolution, executive summary);
- external material used as a reference for form or as inspiration.

## Authority

The files in this folder are **descriptive**, not normative. They show the standard as practiced, and it is
legitimate for an example to diverge from the official template.

Consult references when the task involves text, documents, presentations, spreadsheets, dashboards,
layout, design or another recurring format. Use them to recognize:

- recurring writing style, vocabulary and spelling;
- expected text density and level of detail;
- the anatomy of the material (action title, subtitle, blocks, reading sequence);
- conventions for exhibits, footers, notes and sources;
- how information is organized and the pattern of analysis.

## What this folder never is

**It is not a layout mold.** Recognizing the pattern of writing and structure is different from copying the
composition of an earlier material. The freedom to compose according to the message still applies.

**It is not a brand source.** An example may contain colors, fonts or graphic elements outside the current
standard. For the exact value of a palette, logo, font or icon, use `02.Official_Templates`. External
material has no authority over brand.

**It is not a factual source.** Do not reuse data, figures, names, dates, conclusions or recommendations
from old versions.

## Form precedence

The full chain is in `CLAUDE.md`, section "Form precedence". What it means here: when there is a conflict of
form between an example in this folder and the official template, the template wins; when there is a
conflict between either of them and the material being edited, the current material wins.

## How to consult

Select only the files most comparable to the objective, audience and format of the deliverable. Do not read
the whole folder by default.

The current request, the applicable contexts and the current materials prevail over the references in this
folder.
