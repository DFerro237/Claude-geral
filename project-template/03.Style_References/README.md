# Using the style references

This folder gathers examples of finished materials and other references of form. It serves to recognize how the team's work is actually written and structured.

The main content is the team's own finished materials. The institutional templates are in `02.Official_Templates`, which is a different folder with a different authority.

The folder can stay with only this `README.md` when no reference applies.

## What goes in

- the team's own finished presentations, documents and spreadsheets, inside or outside the official template;
- approved versions of recurring materials (agenda, report, resolution, executive summary);
- external material used as a reference of form or inspiration.

## Authority

The files in this folder are **descriptive**, not normative. They show the practiced standard, and it is legitimate for an example to differ from the official template.

Consult references when the task involves text, a document, a presentation, a spreadsheet, a dashboard, layout, design or another recurring format. Use them to recognize:

- recurring writing style, vocabulary and spelling;
- expected text density and level of detail;
- the anatomy of the material (action title, subtitle, blocks, reading sequence);
- conventions for exhibits, footers, notes and sources;
- how information is organized and the standard of analysis.

## What this folder never is

**It is not a layout mold.** Recognizing the standard of writing and structure is different from copying the composition of an earlier material. The freedom to compose according to the message still applies.

**It is not a brand source.** An example may contain colors, fonts or graphics outside the current standard. For exact values of palette, logo, font or icon, use `02.Official_Templates`. External material has no authority over brand.

**It is not a factual source.** Do not reuse data, numbers, names, dates, conclusions or recommendations from old versions.

## Form precedence

The full chain is in `AGENTS.md`, section "Form precedence". What it means here: when there is a conflict of form between an example in this folder and the official template, the template wins; when there is a conflict between either of them and the material being edited, the current material wins.

## How to consult

Select only the files most comparable to the goal, audience and format of the deliverable. Do not read the whole folder by default.

The current request, the applicable contexts and the current materials prevail over the references in this folder.
