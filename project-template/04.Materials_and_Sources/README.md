# Using the materials and sources

This folder gathers the materials, data, documents and reference bases to be used as input for the current work.

The sources, evidence and databases that feed the analysis, update or preparation of the project's deliverables should preferably be in this folder.

Include here, when applicable:

- reports, spreadsheets, trial balances and databases;
- presentations, pitch decks and documents received;
- transcripts, minutes, exported e-mails and meeting records;
- external sources downloaded or consolidated for reference;
- documents that support facts, numbers, analyses or updates in the deliverable.

These files must be treated as reference sources and evidence for the task.

Before updating, creating or reviewing a deliverable, consult the materials in this folder when they apply to the work.

Do not treat old, incomplete or contradictory materials as a definitive source without assessing their applicability, date, origin and consistency.

## Public source consulted on the spot

Not all evidence arrives as a file. A lookup made during the task in a public database, such as a company registry, an official registration database, an official publication or a regulator's website, is also a source, and sometimes the best available.

When you use one of these, record in the deliverable the date of the lookup, because the result changes without notice and a claim without a date can no longer be verified later. Also record what that database proves and what it does not prove: a database that shows only the current status does not prove when the status changed, and treating the absence of a record as proof of the event produces a conclusion stronger than the source supports.

When the lookup is material to the work, save the result here, with the date in the name, so the next reader can check what was actually seen.

## Preservation

Do not change the files in this folder without explicit authorization. When a material needs to be updated, use it as a source or copy it to the applicable folder, preserving the original.
