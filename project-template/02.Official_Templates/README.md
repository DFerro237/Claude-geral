# Using the official templates

This folder gathers the sanctioned institutional templates and brand material. It is the project's normative source of form.

The folder can stay with only this `README.md` when no template applies.

## Organization

Templates for a specific client go in a subfolder named after that client and apply only to that client. In a project for another client, the previous client's subfolder must be removed, as described in the README of `00.Claude_Context`.

Generic templates, without client branding, go at the root of the folder.

## What goes in

- institutional presentation, document or spreadsheet templates;
- brand manual, visual identity guide, official palette;
- sanctioned layouts, covers, chapter openers and icon galleries;
- official logos and graphic elements.

## Authority

The files in this folder are **normative on brand and form**, within the client they belong to. The exact values come from them:

- palette color codes;
- official font and weights;
- logo, graphic elements and icons;
- approved layouts and structures.

When you need the exact value of a color, the file of an icon or the correct font, consult the official template instead of inferring it from a finished material.

The form precedence chain is in `AGENTS.md`, section "Form precedence". What it means here: the template beats the examples in `03.Style_References`, but loses to the material being edited and to an explicit user instruction. An approved deck that has already settled a given treatment should not be rewritten to fit the template.

## What this folder never is

It is not a factual source. Do not reuse data, numbers, names, dates, projections, conclusions or sample text from a template. Filler content (`Lorem ipsum`, `XXX`, fictitious names, demo values) exists only to show the form.

## How to consult

Open only the template comparable to the format and audience of the deliverable. Do not read the whole folder by default. Institutional templates are often large files, so prefer locating the specific slide or sheet over processing the whole file.

## Preservation

Do not change, move, rename or delete templates without explicit authorization. When generating a deliverable from a template, work on a copy in the applicable destination and preserve the original.
